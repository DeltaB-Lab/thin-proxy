接入方式

Base URL 使用代理地址，API Key 使用这里创建的 Key。

客户端要求 /v1 时，将它加在代理地址后。每个 Key 可配置多个上游并排序。开启“启用故障转移”后，按顺序跳过冷却中的上游；关闭时仅直连第一项。跟随默认上游时直接转发，不读取或记录故障状态。每次请求只访问一项。切换上游、修改绑定和撤销 Key 可能延迟 30 秒生效。

仅开启故障转移的请求遇到网络错误、超时、401 / 403 / 408 / 429 和 5xx 时，会让该上游冷却 30 分钟。本次错误直接返回，由客户端决定是否重试；全部不可用时返回 503 和 Retry-After。冷却到期后，每个实例允许一次请求探测；失败开启下一轮冷却。可在上游卡片手动清除故障状态，允许重新尝试。请求体直接流式转发，不缓存、不重发；大小受 Cloudflare 和上游限制。故障状态保存在 D1，其他实例随配置缓存刷新同步，正常请求不额外查询数据库。
